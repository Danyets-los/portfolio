Это мой выпускной проект из Т-академии

Целью исследования было выявление причин падения GMV за апрель в сервисе доставки продуктов

В сервисе доставки продуктов пользователь может зайти в приложение или на сайт, найти нужные товары, посмотреть карточки товаров, добавить товары в корзину и оформить заказ

Данные за последние 6 месяцев хранятся в 3 наборах данных:
1. Заказы
2. Пользовательская воронка
3. Маркетинговые коммуникации

В ходе работы были построены деревья метрик и срезов, падение GMV декомпозировано по метрикам, выявлена причина падения, проверена статистическая значимость эффектов, а также исключено влияние проводимого А/Б-теста на Nord Star

На основе исследования даны инструкции для бизнеса

Все выкладки оформлены в файл итоговый_проект.ipynb
